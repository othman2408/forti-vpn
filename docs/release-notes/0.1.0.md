# Forti-VPN 0.1.0

The first release of an unofficial native Ubuntu GUI for FortiClient VPN.

- Connect and disconnect with password and MFA prompts.
- Create, view, edit, and delete profiles, with separate server and port fields.
- Choose client certificates with a native file picker.
- Keep the app in the top bar, or disconnect and quit when closing.
- Use system, light, or dark appearance.
- View sanitized diagnostics and copy a troubleshooting report.

## Install

Designed for Ubuntu 26.04 and FortiClient 7.4.3. Download the `.deb` and run:

```bash
sudo apt install ./forti-vpn_0.1.0_all.deb
```

Open **Forti VPN** from the applications menu. FortiClient is installed separately;
the app provides setup guidance if its CLI is missing. Top-bar integration requires
AppIndicator support.

To check the downloaded package, place `SHA256SUMS` beside it and run:

```bash
sha256sum -c SHA256SUMS
```

## Verification

Live VPN testing was completed successfully by the maintainer. Automated checks
cover CLI integration, authentication flows, profile operations, and native UI behavior.

## Notes

The app checks profiles and status on launch and when you refresh. It does not
poll continuously. FortiClient manages the VPN and saved passwords; this app does
not store passwords or MFA codes.

If you previously used the source installer, its per-user launcher and desktop
entry take precedence over the system package. Remove those app files first:

```bash
rm -f ~/.local/bin/forti-vpn ~/.local/share/applications/io.github.fortivpn.Utility.desktop
```

This does not remove FortiClient, VPN profiles, or app preferences.
