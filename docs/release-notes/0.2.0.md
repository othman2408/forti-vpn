# Forti-VPN 0.2.0

A Rust rewrite of the unofficial native GUI for FortiClient VPN, now for all
major Linux distributions.

- Rewritten in Rust with GTK 4 and libadwaita; it needs GTK 4.14 and
  libadwaita 1.5 or newer.
- Packages for Ubuntu and Debian (`.deb`), Fedora, RHEL-compatible systems,
  and openSUSE (`.rpm`), and Arch Linux, plus an experimental Flatpak.
- FortiClient setup guidance for each distribution, including the AUR
  package on Arch, the FortiClient service, and tray support on each desktop.
- A tray icon that shows whether the VPN is connected, on any desktop with
  a panel that shows tray icons.
- Preferences from 0.1.0 are kept.

## Changes in behavior

- When FortiClient has a saved password for a profile, **Connect** now uses
  it, and **Remember password** shows as on and locked. To change the saved
  password, use **Manage Profile → Update Saved Password**.
- When FortiClient's service is stopped, the app says so, and **Set Up
  FortiClient** shows the command to start it:
  `sudo systemctl enable --now forticlient.service`.
- **Disconnect and Quit** quits when FortiClient has never answered (for
  example because its service is stopped): the app cannot have connected.
  If FortiClient stops answering after it was seen, the app offers
  **Quit Anyway** instead of staying open with no way out.
- **Try Again** after a failed **Update Saved Password** repeats the update
  and asks for the password again.
- Without a tray icon, the window says that closing keeps it open, and
  **Settings** shows the command that adds tray support for your system.

## Install

| System | Package |
| --- | --- |
| Ubuntu 24.04 and newer, Debian 13 | `sudo apt install ./forti-vpn_0.2.0-1_amd64.deb` |
| Fedora 43 or newer (tested on Fedora 45), RHEL, AlmaLinux, Rocky Linux 10 | `sudo dnf install ./forti-vpn-0.2.0-1.el10.x86_64.rpm` |
| openSUSE Tumbleweed, Leap 16 | `sudo zypper install --allow-unsigned-rpm ./forti-vpn-0.2.0-1.el10.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./forti-vpn-0.2.0-1-x86_64.pkg.tar.zst` |
| Flatpak (experimental) | `flatpak install --user ./io.github.fortivpn.Utility.flatpak` |

FortiClient is installed separately; the app guides you through setup if its
CLI is missing. See the [README](https://github.com/othman2408/forti-vpn#readme)
for FortiClient, tray, and source installation per distribution.

To check the downloads, place `SHA256SUMS` beside them and run:

```bash
sha256sum -c --ignore-missing SHA256SUMS
```

## Upgrading from 0.1.0

The `.deb` upgrades the 0.1.0 package in place. If you used the 0.1.0
source installer, remove what it put in your home folder: its launcher and
desktop entry take precedence over the package, and its icons would hide
the new app and tray icons. Then refresh the icon cache:

```bash
rm -rf ~/.local/bin/forti-vpn \
  ~/.local/share/applications/io.github.fortivpn.Utility.desktop \
  ~/.local/share/icons/hicolor/scalable/apps/io.github.fortivpn.Utility.svg \
  ~/.local/share/icons/hicolor/symbolic/apps/io.github.fortivpn.Utility-symbolic.svg \
  ~/.local/share/forti-vpn
gtk-update-icon-cache -f -t ~/.local/share/icons/hicolor
```

If you had set `XDG_DATA_HOME`, the installer used it in place of
`~/.local/share`; adjust the paths above. Preferences are kept. FortiClient
and its VPN profiles are not affected.
